# 0g-storage-tutorial

Built with [create-0g-app](https://www.npmjs.com/package/create-0g-app) on the [0G network](https://0g.ai).

## Quick Start

```bash
npm install
cp packages/web/.env.example packages/web/.env.local
# Edit .env.local with your config
npm run dev
```

## Storage

Files are uploaded to 0G decentralized storage via `@0glabs/0g-ts-sdk`.
Edit `packages/web/components/StorageSection.tsx` to customize.
